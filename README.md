A Spotify-inspired music streaming web player built using HTML, CSS, and JavaScript. This project provides a modern music-player interface with playlists, search, playback controls, volume control, progress tracking, and responsive design.

Features
🎵 Spotify-inspired user interface
▶️ Play and pause music
⏭️ Previous and next track controls
🔊 Volume control
📊 Music progress bar
🔍 Search functionality
📚 Playlist and library section
❤️ Like/favorite functionality
📱 Responsive design
⚡ Built with pure HTML, CSS, and JavaScript
📄 Single-file implementation
Technologies Used
HTML5
CSS3
JavaScript
Font Awesome
Google Fonts
